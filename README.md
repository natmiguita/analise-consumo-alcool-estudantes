# analise-consumo-alcool-estudantes
Análise exploratória de dados de estudantes usando SQL, SQLite e DBeaver, com consultas sobre idade, consumo de álcool e hábitos de estudo.

# Análise de dados de estudantes com SQL

Projeto de estudo em andamento, desenvolvido durante meu aprendizado de SQL no curso da DIO.
Escolhi um dataset do Kaggle para praticar os conceitos das aulas com meus próprios exemplos e perguntas.

## Ferramentas utilizadas

- SQL
- SQLite
- DBeaver

## O que pratiquei até agora

- Importação de arquivos CSV para tabelas.
- Seleção de colunas com SELECT.
- Contagem de registros com COUNT.
- Filtros com WHERE e AND.
- Ordenação com ORDER BY.
- Agrupamento com GROUP BY.
- Exportação de resultados para CSV.

## Dados utilizados

Dataset: [Alcohol Effects On Study — Kaggle](https://www.kaggle.com/datasets/whenamancodes/alcohol-effects-on-study).

Foram importadas as tabelas Maths e Portuguese. As consultas exploratórias apresentadas até aqui usam a tabela Maths.

Um dos recortes realizados seleciona estudantes com níveis de consumo de álcool maiores ou iguais a 3 tanto nos dias úteis (Dalc) quanto nos fins de semana (Walc).

## Sobre as análises

Este repositório registra meu processo de aprendizagem e será atualizado conforme eu avançar.

As consultas descrevem os dados da amostra. Elas não demonstram que o consumo de álcool causa determinado desempenho escolar, nem permitem diagnosticar dependência de álcool.
